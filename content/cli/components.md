# vibejs components

List the .vibe components with their props, models and types, without running them.

```sh
vibejs components [--name NAME]
```

## Options

| Option   | Type   | Description              |
| -------- | ------ | ------------------------ |
| `--name` | string | Only the component NAME. |

## Examples

```sh
vibejs components
vibejs components --name TodoList
```
