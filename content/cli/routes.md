# vibejs routes

List the API routes and the UI routes, without starting a server or running UI code.

```sh
vibejs routes [--kind api|ui]
```

## Options

| Option   | Type   | Description                    |
| -------- | ------ | ------------------------------ |
| `--kind` | string | Only the api or the ui routes. |

## Examples

```sh
vibejs routes
vibejs routes --kind api
```
