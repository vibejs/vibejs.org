# vibejs docs

Look up a VIBE code, open a docs page by path, or search the bundled docs, offline.

```sh
vibejs docs <query...>
```

## Arguments

| Name    | Required | Values |
| ------- | -------- | ------ |
| `query` | yes      |        |

## Examples

```sh
vibejs docs VIBE8003
vibejs docs errors/VIBE8004
vibejs docs "unknown option"
```
