# VIBE9803: Invalid error status

> The error {code} of {route} has the status {status}, which is not between 400 and 599.

`generateOpenApi()` documents each code in a route's `errors` as a problem response under its status. A status outside 400–599 is not an error status: a 2xx status would replace the success response, and other numbers are not valid response keys.

### Fix

- Give {code} a 4xx or 5xx status, such as `404` or `409`.
