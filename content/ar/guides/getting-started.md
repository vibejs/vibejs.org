# البدء

تطبيق vibe.js هو حزمة واحدة من ثلاثة أجزاء: الواجهة والخادم والعقود بينهما. أمر واحد ينشئه، وأمر واحد يفحصه كله.

## المتطلبات {#requirements}

- Node.js بالإصدار `^24.15.0 || >=26`.
- مدير حزم: pnpm أو npm أو yarn أو bun. تستخدم الأمثلة pnpm.

## إنشاء تطبيق {#create-an-app}

```sh
pnpm create vibejs my-app
cd my-app
```

مع مدير حزم آخر، شغّل `npm create vibejs@latest my-app` أو `yarn create vibejs my-app` أو `bun create vibejs my-app`. يثبّت أداة التهيئة الاعتماديات بمدير الحزم الذي شغّلها.

## بنية المشروع {#project-layout}

| المسار       | المحتوى                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------- |
| `contracts/` | عقود الـ API: المسارات مع معاملاتها وأجسامها واستجاباتها وأخطائها. تتشاركها الواجهة والخادم. |
| `server/`    | الخادم: الوحدات (modules) والمتحكمات التي تخدم العقود والخدمات.                             |
| `ui/`        | الواجهة: مكوّنات `.vibe` والصفحات والمسارات وعميل الـ API المُنمَّط.                            |
| `AGENTS.md`  | القواعد وفهرس الوثائق لوكلاء البرمجة.                                                        |

## التشغيل {#run-it}

```sh
pnpm dev
```

يخدم `pnpm dev` الواجهة والـ API على منفذ واحد، والـ API تحت `/api`. افتح العنوان الذي يطبعه: تعرض الصفحة الرئيسية الحالة التي تحمّلها من `/api/health`. تُحدَّث تغييرات الواجهة في مكانها، وتعيد تغييرات الخادم تشغيله.

## الفحص {#check-it}

```sh
pnpm vibejs check
```

يفحص `vibejs check` أنواع TypeScript وقوالب `.vibe`، ويجري التدقيق (lint) ويفحص التنسيق ويشغّل الاختبارات مع التغطية، كل ذلك دفعة واحدة. ينتهي برمز 0 عندما ينجح كل شيء، ويطبع كل مشكلة مع ملفها وسطرها وعمودها ورابط وثائقها.

## إعداد المحرر {#editor-setup}

ثبّت إضافات VS Code الموصى بها التي يسردها التطبيق في `.vscode/extensions.json`:

- **vibe.js** (`vibejs.vibejs`): تلوين الصياغة، وفحص الأنواع والتمرير للتعريف والانتقال إليه في ملفات `.vibe`.
- **TypeScript 7** (`TypeScriptTeam.native-preview`): خدمة لغة TypeScript التي تفحص ملفات `.vibe` عبر `@usevibejs/language-tools` الخاصة بالتطبيق.
- **Oxc** (`oxc.oxc-vscode`): التدقيق والتنسيق عند الحفظ.

يشغّل فحص الأنواع شيفرة المشروع، لذا يحتاج إلى مساحة عمل موثوقة. وبدون إضافة TypeScript 7 أو الثقة، يعرض المحرر [VIBE6101](https://vibejs.org/v0/errors/VIBE6101) أو [VIBE6102](https://vibejs.org/v0/errors/VIBE6102) ويواصل تلوين الصياغة.

لـ Neovim والمحررات الأخرى، وللقيود المعروفة واستكشاف الأخطاء، راجع [إعداد المحرر](https://vibejs.org/v0/guides/editors).

## وكلاء البرمجة {#coding-agents}

يحتوي `AGENTS.md` على كتلة من قواعد vibe.js لوكلاء البرمجة: الأوامر الدقيقة، والقواعد التي يخطئ فيها الوكلاء أكثر من غيرها، وفهرس للوثائق التي تأتي مع التطبيق في `node_modules/@usevibejs/cli/dist/docs`، ليقرأ الوكيل وثائق الإصدار المثبّت. يُبقي `vibejs agents sync` و`vibejs dev` الكتلة محدّثة؛ اكتب ملاحظاتك الخاصة خارج علاماتها. راجع [سطر الأوامر ووكلاء الذكاء الاصطناعي](https://vibejs.org/v0/guides/ai-agents).
