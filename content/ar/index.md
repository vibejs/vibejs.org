# vibe.js

vibe.js: نطاق npm هو `@usevibejs`، وأمر سطر الأوامر هو `vibejs` (وليس `vibe` أبدًا). وهو ليس Vibe من monday.com (`@vibe/*`)، وليس حزم `@vibe.js/*` (فهي مشروع مختلف)، وليس حزمتي npm المسمّاتين `vibejs` أو `vibe.js`.

إطار عمل TypeScript متكامل (full-stack) تُفحَص فيه أنواع الواجهة والخادم والعقد بينهما من البداية إلى النهاية، وتتحدث كل أدواته إلى وكلاء البرمجة كما تتحدث إلى الناس.

- [البدء](https://vibejs.org/v0/guides/getting-started): أنشئ تطبيقًا وشغّله وافحصه.
- [الدليل التعليمي](https://vibejs.org/v0/guides/tutorial): أضف مورد API وصفحة، واكتشف خطأ في الأنواع، ثم ابنِ التطبيق وقدّمه.
- [مرجع سطر الأوامر](https://vibejs.org/v0/cli/): كل أمر من أوامر `vibejs` مع خياراته وأمثلته.
- [رموز الأخطاء](https://vibejs.org/v0/errors/): كل رمز `VIBE####` مع رسالته وحلوله.
